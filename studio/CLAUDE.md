# CLAUDE.md

## Purpose
This project is an MVP frontend built with Svelte (no SvelteKit).
The goal is to move fast with small, controlled, incremental changes.
The human (Manuel) is the reviewer and decision-maker.

## Core Rules (MANDATORY)
- DO NOT change unrelated files
- DO NOT introduce new dependencies unless explicitly approved
- DO NOT restructure folders unless explicitly asked
- ALWAYS prefer the smallest possible diff
- KEEP solutions simple and pragmatic (MVP mindset)

## Code Style
- Keep files short when possible
- Prefer local state over shared state

## File Editing Rules
- Do not rewrite entire files if only small edits are needed
- Preserve existing formatting and structure

## Behavior Expectations
- If unsure, ASK instead of assuming
- If a better approach exists, SUGGEST it briefly but do not implement it unless approved
- Optimize for control and clarity, not speed

## Output Style
- Be concise
- Focus only on the requested change
- No extra features
